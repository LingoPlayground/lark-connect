## 2. 验证记录

- 自动化：`npm run quality` 通过，11 项测试覆盖会话绑定、显式接管、旧代次、检查点、锁恢复、纯技能载荷及发布入口；`npm ci --ignore-scripts` 成功。
- 安装：2026-09-22 更名后，Codex 使用隔离配置目录从本地市场安装插件 `0.2.0`，安装目录仅有 `lark-chat-session` 技能及会话脚本、无模型上下文协议描述；Claude Code 插件和市场清单严格校验通过。
- 真实飞书：2026-09-22 在用户指定的验收群，以用户身份发送消息、补查历史、回复原消息并添加 `OK` 反应；重复读取时可见已有回复与反应。本轮又给既有用户身份测试回复添加 `DONE` 标记，并在历史查询中读回。在用户与当前机器人私聊，以机器人身份收到 `im.message.receive_v1` 事件，随后补查、回复并确认；事件消费者退出后发送的另一条消息仍被历史补查并回复。用户身份还完成一项非聊天只读查询。测试绑定已停止，临时检查点已清理。记录不含聊天标识、个人消息或凭据。
- 待验证：安装后智能体实际按技能持续工作；Codex 心跳与 Claude Code `/loop` 无人值守唤醒；机器人群聊提及过滤、话题群旧话题回复、媒体与提及、无需回应的用户消息、权限失败和发送结果不明等分支。当前不得把上述已完成的命令行演练等同于完整产品验收。
